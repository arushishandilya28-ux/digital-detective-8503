# Mission 01 — Know your computer

## 1. Task / objective
Describe input, processing, output and storage (IPOS), classify hardware and software, and identify computer-based systems.

## 2. Work completed
The examples below are reference examples. Replace any item that does not match your own use.

### Task 1.1 — Example: typing and saving a document
| Stage | What happens | Component |
|---|---|---|
| Input | Keys are pressed and text is entered. | Keyboard |
| Processing | The editor updates the document and keeps working data in memory. | CPU and RAM |
| Output | The new text appears on screen. | Display |
| Storage | Saving writes the document for later use. | SSD or cloud storage |

### Task 1.2 — Example hardware and software
| Item | Type | Software category | Purpose |
|---|---|---|---|
| Keyboard | Hardware | — | Enters text and commands |
| Trackpad or mouse | Hardware | — | Moves the pointer and selects items |
| Display | Hardware | — | Shows images and text |
| SSD | Hardware | — | Keeps files when power is off |
| macOS | Software | Operating system | Manages hardware, files and applications |
| Web browser | Software | Application | Opens websites |
| VS Code | Software | Application | Edits code and text files |
| Activity Monitor | Software | Utility | Displays processes and resource use |

### Task 1.3 — Example everyday systems
| System | Main purpose | Input | Output |
|---|---|---|---|
| ATM | Provides banking services | Card and PIN | Cash or account information |
| Ticket machine | Sells travel tickets | Destination and payment | Ticket |
| Traffic signal | Controls road traffic | Timers and sensors | Red, amber or green lights |
